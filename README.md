# Base-verktøy

Verktøy for elektro og bygg som kjører i nettleseren: https://magnusgitt.github.io

- `pdfbase/`: PDF- og tegningsverktøy (PDF, DWG, måling, beskrivelser og priser)
- `planbase/`: kalender og fremdriftsplan

Alt behandles lokalt i nettleseren. Ingen filer lastes opp.

Tredjepartskomponenter i pdfbase: LibreDWG via libredwg-web (GPL-3.0), Tesseract.js (Apache-2.0), pdf.js (Apache-2.0), pdf-lib (MIT), JSZip (MIT).
